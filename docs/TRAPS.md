# Tool traps in this repo

One line each: the job or symptom, what works, what fails, the date. `grep -n -i "<tool>" docs/TRAPS.md` before a tool's first use here. Instrument traps (assertions, mutations, jsdom) are in `docs/WORKING.md` section 3; machine-wide traps are in the root `TOOLING.md`.

## Suite and mutations

- `tools/section.mjs --mutations` in a worktree with no `node_modules` refuses every lane ("not green", `Cannot find package jsdom`, or "no totals"): the lane copy sits in Temp where nothing resolves above it; give the worktree its own (a junction, or `npm ci` with no junction present) first (20 Oct 2026).
- A worktree's `node_modules` junction pointing at an emptied folder fails the suite at once on a missing `jsdom`, and an app-made worktree has none at all (a section reading `node_modules\wrangler\config-schema.json` by path fails a whole shard; the gate fails "the workflows parse" on a missing `yaml`): `unlink node_modules`, then `npm ci` in the worktree itself (29 Sep, 30 Sep, 10 Oct 2026).
- No post-checkout hook here (removed 18 Oct 2026 on his word): through a junction, an `npm ci` in a worktree rewrites the main checkout's packages, so link by hand and unlink before `git worktree remove`.
- A mutation that makes the page read again on every redraw never lets `tools/section.mjs` finish (the jsdom page fetches and redraws forever): write a mutation that ends, such as dropping a guard so a read happens twice (21 Oct 2026).
- A mutation run stopped mid-way (TaskStop, interrupt) leaves the mutated file and `test/.shard-section-*.mjs` and the next run refuses: `git checkout -- <file>` and recycle the shard file; with uncommitted work restore from the kept original in `%TEMP%\salt-section-*\` (path printed at the run's head), `diff` first, and copy the file aside before any mutation run (12 Oct 2026).
- The put-back after a mutation can fail on Windows (`writeFileSync` threw `UNKNOWN` errno -4094 on `stmt/owner.js` and the run died with the mutation in place): same restore from the kept original (16 Oct 2026).
- `tools/section.mjs --mutations` cannot mutate `test/verify.mjs` itself (it reads the suite before applying, so any mutation reports UNNOTICED): prove a suite guard with `--master <copy>` or by hand (copy aside, edit, run the section, copy back, compare `sha256sum`) (28 Sep 2026).
- `tools/section.mjs` will not start while an `npm test` shard file is live, and an edit made while `npm test` runs gives a false red: edit between runs, run mutations after the suite not beside it, and rerun a red section alone before reading it as a regression (10 and 11 Oct 2026).
- TaskStop on a background `npm test` does not kill its shard processes, and a background `npm test > log 2>&1; echo exit $?` reports the echo's exit 0: give each run its own log file and read the `exit N` line and the log's last line (5 and 11 Oct 2026).
- A mutation run takes minutes when each wait runs to its cap (a mutation that makes Back close nothing): cap a test's polls near 2 s and run a long manifest as four slices in four `git archive` copies with a `node_modules` junction each (13 Oct 2026).
- A jsdom window left open holds Node while the page has a timer armed (the desk's next-theme `setTimeout`, hours away): `openMaster` in `tools/payload.mjs` runs a timer over a minute unref'd and clears it on close; probe a tool with `timeout 60 node <tool>` (05 Oct 2026, v1022).
- A page test that installs `win.fetch` after `new JSDOM(...)` and taps at once finds the page's own first read in flight (`sheetBusy` skips a second): flush with `for (let i = 0; i < 30; i++) await Promise.resolve();`, never a `setTimeout`, since the suite counts fixed pauses (11 Oct 2026).
- A test that holds a route cannot use `pageWork(win).quiet()` while it is held (it waits 60 s for the held fetch): poll a bounded condition while held, release, then `quiet()`; a gate built to hold a route must work out the answer when the request is made and open once (11 Oct 2026).
- Owner-script names can clash with `CLIENT_JS` (`stmt/owner.js` is spliced into the customer page's one scope, so a top-level `var oOpen` overwrote the customer's function and only the full suite's S1 1.21 failed): grep `function <name>` in `stmt/page.js` and `stmt/owner.js` first, and run the full suite or `node tools/section.mjs "S1 1.21"` after adding a top-level name to `owner.js` (11 Oct 2026).
- jsdom's `getComputedStyle` resolves no `var()` and lets a class's `display:flex` beat `hidden`: compare cascades by listing each element's matching rules in order from `document.styleSheets` (recursing into `@media`) over a `git archive origin/master stmt src engine | tar -x -C <scratch>/base` tree, and read a `[hidden]` rule off the sheet (`selectorText === ".payfoot[hidden]"`), proved red by emptying it (11 Oct 2026).
- jsdom runs `history.back()` and `go()` as queued tasks and two `go(-1)` in one tick collapse into one: batch moves into a single `go(-k)`, count the page's own `popstate` instead of pausing, and put back a test's `replaceState` mark after each tab tap (13 Oct 2026).
- A width in jsdom: rewrite every width query that holds to `@media all` (`atWidth` in `test/counter-tablet.mjs`) and `getComputedStyle` then gives a Sheet's placement even while hidden; a sticky pane starting 100px down has its foot under a fixed bar at scroll 0 by construction, so measure with the page and the pane scrolled to their ends (12 Oct 2026).
- A Sheet over a Sheet: the system's Sheet is `z-index` 70 and 71, so a second Sheet is no higher by coming later in the page; give it its own rule (the Counter's `#ynScrim` 72, `.ynsheet` 73) and prove the order by `getComputedStyle(...).zIndex` (11 Oct 2026).
- Once every Sheet shuts the page behind it (`behind()`, `inert`), a test reading `[inert]` on a page that has chosen no look sees the first-open look Sheet's shut page: set `salt-look` in `beforeParse` (11 Oct 2026).
- A mutation whose first red check crashes the section ("no totals") leaves every later check unproved: a check that comes last needs a mutation that fails only it (a native call inside a try/catch) (11 Oct 2026).
- A new open fixture order in `tools/testfix.mjs` shifts every test that counts the practice account's open orders against the limit (`test/maker-claims.mjs` "Concurrent example cancel..." filters other features' cases out): filter a new open case there by its id (11 Oct 2026).
- A changed code line that a mutation needle names breaks "every mutation needle still finds"; copying a rule into the customer's block made an old needle occur twice: put the selector in front of the needle, and run that check after any CSS that repeats a line (12 Oct 2026).
- Python's `open(path, "w")` on Windows writes CRLF and turned a 6,281-line LF `stmt/page.js` into CRLF (118 needles then read "occurs nowhere"): edit through Node (`writeFileSync`) or Python with `newline="\n"` on both opens, count `\r$` with the Grep tool before the needle check, fix with a Node `replace(/\r\n/g, "\n")` (13 Oct 2026).
- The Edit tool writes a BOM where the text held the escape `\uFEFF`: after such an Edit run `grep -n 'uFEFF'` and restore the escape by a scripted replace; the Grep tool's ripgrep has no look-around, so search a short literal (11 Oct 2026).
- `node -e` importing a tool that has a main guard throws (`pathToFileURL(process.argv[1])` is undefined, ERR_INVALID_ARG_TYPE): write the snippet to a scratch `.mjs` and run that; a regex built from a JS string (`new RegExp("\\b" + w)`) through a heredoc, sed or nested `node -e` can lose a backslash and land as a backspace, so write it with Edit or a script file and check the bytes with `od -c` (10 Nov 2026).
- Splitting one working tree into commits by part: commit all as one WIP, rebase onto origin, `git reset origin/master` (mixed), stage hunk by hunk with a script over `git diff -U0` fed to `git apply --cached --unidiff-zero`, run each commit's section and mutations on its intermediate file state, compare the tip with the WIP sha after; `git commit --fixup=<sha>` then `GIT_SEQUENCE_EDITOR=true git rebase -i --autosquash origin/master` runs with no editor (11 Oct 2026).
- A builder's worktree folder removed by the harness after an API timeout (gitdir file gone, branch kept): `git worktree prune`, delete the stale branch, `git worktree add .claude/worktrees/<name> -b <branch> origin/master`, `npm ci` (11 Oct 2026).
- A long `python - <<'EOF'` in the Bash tool died with "unexpected EOF", a `\\n` in a heredoc reached Python as a real newline, and a worktree-isolated agent's Bash refuses a heredoc followed by `node` or `python` on the same line: write the script with the Write tool into the scratchpad and run `python <file> <target>`; put a needle holding a newline in by the Edit tool (11 and 13 Oct 2026).
- Bash refuses `cd dir && rm -rf parts/*` (a relative glob after a `cd`): use a fresh scratch folder or the Recycle Bin (11 Oct 2026).
- `node tools/section.mjs "v453..." --mutations <file in the scratchpad>` once ran its unmutated pass against what read as the mutated master and refused: keep a section's mutations file under `test/`, or prove by hand with `--master <mutated copy>` against a passing `--master <plain copy>` (cause unverified; also in `CLAUDE.md`).

## Browser pane and the Counter harness

- Drive live Salt Admin in the Browser pane (it holds his Access login): orders are `GET /all/maker/review`, never `/all/maker/orders` (404); open an account at `/all#acct/<code>`; open an order row by a `computer` click at coordinates off a fresh screenshot; set a field with `value` plus `input` and `change` events in `javascript_tool`, checking the card's id and the pill's words in the same script before the click that sends; a `ref` click on a list row goes stale when the list redraws on its poll, and a scripted `.click()` on a row opens nothing (12 Nov 2026).
- Preview a worktree's build in the Browser pane: `preview_start` reads the MAIN checkout's `.claude/launch.json` and runs from there, so `salt-static` serves main's `public/` (check `SALT_BUILD_ID`); copy the worktree's `public/` into a folder a config already names and nothing else uses (`salt-wt-static`: `.claude/worktrees/design/public`), then recycle the copy; a config added to the worktree's own `launch.json` is not read and the worktree's `file:///` URL is refused; `preview_start` by name needs the session's root to be `Code\` (28 Sep 2026).
- A page served as bare HTML with "MIME type ('text/html')" errors while `curl` gets `text/css` is a stale service worker on that localhost port from an earlier session: unregister it and clear `caches` in the page, then reload (28 Sep 2026).
- QR Command before and after (10 Oct 2026): `node node_modules/wrangler/bin/wrangler.js dev --port <p> --local` from the Bash tool in the background, one in the main checkout and one in the worktree, then `preview_start` with `url: http://localhost:<p>`; compare by hashing every element's computed style and every canvas's `toDataURL`.
- A scrolled page under the mobile preset captures black, a Browser-pane screenshot at a scaled size crops instead of scaling, one taken straight after a tap may tile (four copies of the top-left at 768 wide), and the pane reads a transition's old colour for 500 ms after `data-theme` is set: measure with `getBoundingClientRect`, `elementFromPoint`, `offsetWidth` in `javascript_tool` (the pane's 0.3px scale error shows as a bar 63.7 tall), wait before reading a colour, and take a plain full-scale shot to look (28 Sep, 11 and 12 Oct 2026).
- The Counter's CSP (`script-src`, `style-src` self-only) blocks a Playwright `addStyleTag` and an injected script: measure the real page with `getBoundingClientRect` and `getComputedStyle`, and use `bypassCSP: true` only for a changed rule in scratch, never to prove a shipped page (12 Oct 2026).
- `serve-customer.mjs` (counter-render) defaults `--repo` to another worktree (`counter-map`) and imports `stmt/page.js` once: pass `--repo <worktree>`, restart after any edit (`Get-NetTCPConnection -LocalPort <port>`, `Stop-Process`; the killed task then reports exit 127, which is the kill), list accounts with `node serve-customer.mjs accounts`, and `localStorage.clear()` before signing in as another account or `localStorage.setItem('salt-look','tide')` plus a reload for the other theme (11 Oct 2026).
- `counter-render` drew "Your account could not be read" for a worktree's page (its fixture lacks `liveStatus:'fixture'`): run the real `stmt/worker.js` on an in-memory KV with the practice accounts (`TEST_PASS` in `stmt/testfix.js`) from a scratch script outside the repo and restart it after every `stmt/page.js` edit (11 Oct 2026).
- `serve-customer.mjs` has no `GET /pay/accounts` route, so the pay sheet logs a 404 console error: run a copy from the scratch dir with `p === "/pay/accounts"` in its `needs` list and a `json(res, { ok: true, accounts: {} })` answer; `startAdminHarness` appends `requests.jsonl` beside `serve-admin.mjs`, so run a copy of it too (`logFile` in the scratch dir); a baseline is `git archive <sha> stmt design tools engine ledger master test package.json | tar -x -C <scratch>` with a `node_modules` junction (12 Oct 2026).
- Counter stress runner (`counter-redesign\map\customer\stress\stress-customer.mjs`): give post-action `locator.evaluate` reads `{ timeout: 1500 }` (a gone element waits 30 s); workers started together raced one temp book file (now one file a process); a rerun without `--out <other folder>` overwrites the first run's JSON and md; keep the double tap and five taps re-reading the locator each time; merge reruns newest job first, never replacing a key already filed; after a rule edit rerun every control it touches on the final file (11 Oct 2026).
- Stress runner flags and copies: the flag is `--only <ids>` (no `--ids`); a copy needs `serve-customer.mjs`, `scenes-customer.mjs`, `shoot-customer.mjs` and `controls-customer.json` beside it, `SALT_REPO` at the checkout and `SALT_PW` at the Playwright folder; a `git archive` snapshot as `SALT_REPO` also needs `wrangler.stmt.jsonc` and `wrangler.jsonc` or every worker dies and all rows read `unclear`; a driver waiting for a line the child never writes idles to its cap, so wait on the child's exit event (13 Oct 2026).
- WebAuthn on the harness needs `http://localhost:<port>` (an IP address is not a valid RP ID), and a second `credentials.get()` while one is pending is rejected with `OperationError: A request is already pending` (11 Oct 2026).
- Counter admin stress: one shared Chromium dies after a single locator timeout, so launch a fresh browser per case; `locator.nth(i)` re-resolves on every call, so take `locator.elementHandle()` before the first tap and tap that for every repeat; `click` on a disabled button waits for it to re-enable, so hold the response (`fault({delay})`) to test a repeat in flight; a stub answering every repeat 200 in 10 ms cannot show a guard, so keep the request id once per order (same id and content: `again`; other content: 409) (11 Oct 2026).

## Wrangler and deploy

- `pull-vault.mjs` or `seed-vault.mjs` answering `Unexpected token '<', "<!DOCTYPE "...`: the Desk's Access gate served its login page because `SALT_ACCESS_JWT` was unset, and under pair authority the tools also need `SALT_WRITE_KEY`; `cloudflared` is at `C:\Program Files (x86)\cloudflared\cloudflared.exe` (not on an open terminal's PATH until restarted); set the token with `access token -app=...`, never `access login` (it prints it), read the write key with `Read-Host -MaskInput`, run from the repo folder or Node looks for `tools\` under the current folder (11 and 13 Oct 2026).
- `update.mjs` redeploys an unchanged build when the checkout has no `.deployed.json` (the laptop cannot read live `/rev`, Access answers 302, so `deployVerdict` calls it undeployed and `wrangler deploy` can time out and print UPDATE INCOMPLETE after the push succeeded): check the last Cloud commit run's "The phone is serving it" line, and if it names the `public/rev.json` id no deploy is owed (07 Oct 2026).
- `node tools/orders-kv.mjs --check` needs `STMT_URL` and `STMT_DESK_KEY` in the environment, which his terminal does not hold: read a tool's header before handing him its command, and confirm old order keys are gone with `npx wrangler kv key list --namespace-id <id from wrangler.stmt.jsonc> --remote --prefix order:` (and `aclaim:`, `thr:`), which needs only his wrangler login (13 Oct 2026).
- `drafts.mjs --approved` answering "unrecognized token: "\" at offset 116" (7500) is multi-line SQL, not the token (a template-literal SELECT reaches D1 through a shell with each newline a literal backslash-n): read the approved count in one line, `npx wrangler d1 execute salt_ledger --remote --json --command "SELECT COUNT(*) AS n FROM draft WHERE status='approved' AND committed_at IS NULL"` (10 Oct 2026).
- Durable Object PITR refuses a time before the database existed (`getBookmarkForTime(t)` throws "Requested time is before this database existed." for a stamp just before the first commit, a 500 if unhandled): read a minute after the first write and catch it; `ctx.abort()` kills the in-flight answer, so arm and abort are two calls and the lost answer is expected; PITR has no local support, so fake it in node (bookmark = table copy) (20 Oct 2026).
- A laptop queue key without `device` broke Counter Admin's Needs you (`deviceQueueRecords` threw "no matching owner record", `/all/maker/review` answered 502 and Needs you read "Not read: orders and rows" under a false "Nothing needs you"): the value is `{"device":"laptop-<name>","queue":[...]}` with the device equal to the key after `q:` (15 Oct 2026).
- `cloud-commit.yml` job `chain` checks out `{ ref: master }`, so `gh workflow run cloud-commit.yml --ref <branch> -f probe_key=true` uses the branch's workflow file but master's `tools/`; a change to `tools/foldcall.mjs --probe` is proved live only after it is on master (26 Sep 2026).

## Actions and CI

- A new Durable Object migration tag races its two deployers (Workers Builds applied `book-v1` a second before the Actions `chain` Deploy, which failed with "Actor migration tag precondition failed, got tag '' when expected tag is 'book-v1'" while the Worker was live on the new build): `gh run rerun <id> --failed` and the second Deploy finds the tag applied (18 Oct 2026, #193).
- Cloud commit's "Deploy the statements site" can fail on a Cloudflare API `504 Gateway Timeout` ("Received a malformed response from the API", an HTML page), transient on any call: every chain step is safe to repeat, so `gh run rerun <id> --failed` spaced about ten minutes apart, checking cloudflarestatus.com's `api/v2/summary.json` between (12 Oct 2026).
