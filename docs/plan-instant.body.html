How it stays safe

The instant call runs the same pass as the minute, and that pass already marks each stage it queues, so a move reaching the Desk twice (by the call and by the minute) is queued once. Your yes in advance is spent only when the row equals what you were shown, as now. The call is behind the key the two Workers already share, and carries only "something moved".

Each step is checked as every money change is: Fable reviews it through the API, each new check is proved by breaking it, the full suite runs, then one version is pushed and proved live.
