The laptop desk

him

One reason only: Names & IDs, putting a real name against a roster code. Plaintext names never reach the cloud, so this panel exists nowhere else. The cloud desk has Add ID and Amend ID instead, which file a name encrypted on the device.

Open Salt Command.bat

Serves the repo's master on localhost:8766 and opens it; closing the desk stops the server. Nothing on the laptop builds, deploys, commits or pushes.

The customer's side

A second Worker on its own cryptic address, holding ciphertext and nothing else. No brand anywhere on it, and no real name, because none exists there to use.

him

To open any account exactly as its holder sees it, and to check a price list is current: a customer's list is sealed at publish time, so it is only as fresh as the last publish. Behind Cloudflare Access, with the token verified again in the Worker.

Guest links

him

To mint a board for a stranger a customer introduced, and to revoke it or count its opens later. A panel inside the owner's list, not an address of its own: /all/refs is the JSON behind it and answers nothing a browser can read. What guards a mint is the introducer's username, which must be one the roster holds; the guest's level then follows from their tier, two above where there is room.

A guest board

stranger

What a stranger is handed. One board and nothing else, no script at all. The open one: no Access, no password, because the id in the path is the whole credential. No fixed address to bookmark: open one from the owner's list to check it renders.

/g/<id>

Machinery, not surfaces

Nothing here shows the book. They are where you look when something that should have happened by itself did not.

The command line

him

The whole ship in one command: drain, build, test, deploy on an id change, commit, push, then prove master, the build, the live site and origin all agree.

Actions

him

When a phone approval should have folded and did not. Only this job does the whole job: fold, gate, deploy, prove, mark committed, re-seed, publish, suite. Read the step list, because a skipped step is green too.

github.com/maakmal97/salt-command/actions

Workers Builds

him

When the phone is serving an older build than the repo. It deploys the tip of master and stops: it never folds, never marks a draft committed, never writes D1, and its failure is silent. Read its build logs, not the dashboard summary.
