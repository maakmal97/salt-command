# Counter maker replacement inventory

The inventory is a source/control inventory, not owner acceptance. Desk write controls remain
available until the replacements pass genuine owner acceptance. All Counter Admin routes below
remain under the existing verified-owner `/all` boundary. A generic input route is not a
replacement for an absent control.

## Retirement gates

The missing controls above remain open work. Local JWT fixtures prove server boundary behavior,
not a genuine owner session. Positive live owner/keyed-vault acceptance remains unverified.
No Desk input is retired on the strength of this inventory, a generated catalog, or the generic
Maker input allowlist. Pricing rules, restricted amendment kinds and sealed history remain
unchanged.

Merged #81 resolves the five-form input-receipt sweep: stock count, tier setting, tip hush and
printed board sizes release their timestamp/signature through the common confirmed-success
hook, including a successful retained retry. Automatic offsets use the retained sender with
the narrow canonical `{at,code,rid,date}` body. The generated geography seam includes `TIP_ID`;
unsupported offset metadata and invalid tip IDs are refused before transport. Actual generated
page lifecycle checks prove confirmed new intent and unchanged uncertain retries; the independent
mutations are red. These implementation proofs are not owner acceptance.

## The Desk is a dashboard (his decision of 06 Oct 2026)

The master draws no control that writes: Approve, Enter and Network inputs, the order cards' taps, the order button, the ledger pen, the drift, tier, rewards and map controls, and the Whiteboard's Snooze and Dismiss are removed. Site Orders is a read-only list with a text pointer to Counter Admin, not a cross-host link: rule 2 keeps the customer-site address out of the public Desk. The Worker's write routes stay, since the bridge calls them. A test drives every button of every view and fails on a queued entry or a POST. This merges only after the owner accepts Counter Admin review.

Counter Admin now carries the restock date (Restock date card, `/all/maker/expected`; idempotent, a book and a day or null, so no `rid`) and re-entering a rejected sale (a new SELL only: a resale, a note or an order code is blocked, since prose stays off the Counter, rules 2 and 3). The earlier statement that Whiteboard hush had no Counter control conflicts with the generated Tips/Hush tip source listed above; that retirement classification remains unresolved.

Read views: Today, the boundaries table and the Order book show one row a party (06 Oct 2026, his instruction). Today also merges the same warning on several parties into one row; sums add, the date is the oldest, and a table's total is the sum of what it prints. The Site Orders view says decisions happen in Counter Admin but has no clickable link: the Counter shares the customer-site host, which rule 2 keeps out of the public Desk.
